# Farm tracking device
The rapid advancement of the Internet of Things (IoT) and smart sensing technologies
has created new opportunities for improving livestock management and animal welfare in
modern agriculture. This study presents the development of an IoT-based smart wearable
device for real-time monitoring of the health and activity of farm animals. The proposed
system was designed to assist farmers and herdsmen in tracking animal movement,
behavior, and environmental conditions remotely, thereby improving farm management
efficiency, animal welfare, and early disease detection.
The developed system consists of two main units: an animal collar node and a herdsman
gateway node. The animal collar node integrates an ESP32 microcontroller, MPU9250
motion sensor, thermistor temperature sensor, rechargeable battery, and wireless
communication capability based on ESP-MESH technology. The herdsman gateway node
incorporates an ESP32 microcontroller, GPS module, LoRa communication module, and
rechargeable power supply. Communication between collar nodes and the gateway was
achieved using ESP-MESH networking, while long-range transmission from the gateway
to the monitoring station was implemented using LoRa technology.
